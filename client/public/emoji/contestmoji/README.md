# Contestmoji

The SVG files in this folder are the Contestmoji set by Mace Dev.

- Source: https://github.com/macedeveloper/contestmoji
- Website: https://macestudios.ru/contestmoji/
- Copyright: Mace Dev / macestudios.ru. Used with permission.

Slopcall bundles these files locally so the emoji picker and messages work offline.
Do not load the set from a CDN at runtime.
