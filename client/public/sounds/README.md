# Slopcall sound effects

These are generated placeholder WAV files. The app references them by filename, so they can be replaced with your own audio without changing any code.

- `mic-mute.wav` / `mic-unmute.wav`
- `deafen.wav` / `undeafen.wav`
- `voice-join.wav` / `voice-leave.wav` / `voice-error.wav`
- `peer-join.wav` / `peer-leave.wav`
- `message.wav`
- `reconnected.wav` / `disconnect.wav`

Regenerate the placeholders with:

```sh
npm run make:sounds
```
