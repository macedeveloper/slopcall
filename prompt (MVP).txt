# Project

Name: Slopcall

Description: Mini Discord x TeamSpeak clone that just works.

## MVP features (Minimum Viable Product):
- Calls & Group calls, messages.
- No pretty ui, no animations, just base app. (yet)
- No account system. (yet)
1. I can open the app, set a nickname, and join a text channel.
2. I can send a message and other people in the channel see it within ~1s.
3. I can join a voice room and hear others; others hear me.
4. I can mute/unmute my mic and deafen/undeafen my audio via hotkeys.
5. I can set a per-user playback volume for each person in the call.
6. I can leave the voice room and the text channel without reloading.

## Necessary features:
- Hotkeys for: Microphone disabling, Audio on/off.
- Volume settings for each user in call.
- Calls & Group calls
- Messages
- Nickname choosing

## Later features (do not build yet):
- Encryption (secure secret messaging and calls)
- Profile pictures
- Markdown
- File sending (256 MB cap, files above 32 MB gets deleted after 7 days, other files after 30 days.)
- Screensharing

## Criteria:
- Project should be lightweight and easily runnable on slow devices (Client) and our ubuntu server (`server_characteristics.txt`)
- User can only be in one call at a time.
- Should support English and Russian languages. Changeable in settings, reads from system for defaults.
- Should sit in tray like Discord. Add actions on RMB on tray icon.

## Other data:
- I will deploy on server through filezilla and ssh connection. (there is no script setted up)
- Frontend framework is up to you. It should be able to satisfy design criteria, be lightweight, fast and unintrusive.
