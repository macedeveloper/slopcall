# AGENTS.md

## Project map
- `server/` — Node 20+ (`ws` only, no database). Messages are append-only JSONL in `server/data/`; uploads live there too.
- `client/` — Svelte 5 + Vite 8 + Tauri 2. `src/lib/state.svelte.ts` is the single `AppState`; WebSocket types are in `src/lib/types.ts`, client transport in `src/lib/ws.ts`, WebRTC in `src/lib/voice.ts`.
- No root workspace/package. Run npm installs and scripts separately in `server/` and `client/`.
- `prompt.md` is the roadmap; `done.md` is the progress/release log. Do **not** read `prompt (MVP).txt` (explicitly outdated).
- There is no lint/formatter config. `cd client && npm run check` is the static gate.

## Commands
- Server dev: `cd server && npm start` (port 8787). Watch mode: `npm run dev`.
- Client dev: `cd client && npm run dev` (fixed port 1420, `strictPort`). Real desktop shell: `npm run tauri dev`.
- Client checks: `cd client && npm run check`. Vite-only build: `npm run build`. Installer: `npm run tauri build` (NSIS output under `client/src-tauri/target/release/bundle/nsis/`).
- Server tests: `cd server && npm test` (`node --test`; tests spawn temporary servers). If it times out, check for leftover `node --test` child processes before rerunning.
- E2E: server on 8787 + Vite on 1420 must already be running; then `cd client && npm run test:e2e`. It uses installed Microsoft Edge (`channel: 'msedge'`) and `window.__slopcall`, which exists only in dev builds. If it hangs at `page.goto`, verify Playwright's Edge can reach loopback before changing app code.
- Changing the Vite port requires updating `client/vite.config.ts`, `client/src-tauri/tauri.conf.json` (`devUrl`), and `client/scripts/smoke.mjs`.

## Client conventions
- Use Svelte 5 runes (`$state`, `$derived`, `$props`), not Svelte 4 stores. Import the singleton as `import { app } from '../lib/state.svelte'`.
- Every user-facing string must be added to both the EN and RU sections of `client/src/lib/i18n.ts`; keys are typed.
- Settings are auto-saved (immediate preferences; nickname/server on blur/close). Preserve that behavior; do not reintroduce a Save/Cancel flow.
- Reuse the CSS variables/tokens in `client/src/app.css`; do not invent new colors.
- `client/src/lib/icons.ts` is generated by `scripts/extract-icons.mjs`. Add icon names to its `map` and regenerate rather than hand-editing paths; the script needs `node_modules/bootstrap-icons`, which is not currently a declared dependency. `contestmoji.ts` and `public/sounds/` are also generated/vendored.
- The JXL decoder under `client/src/lib/jxl/` is vendored, licensed Apache-2.0, and loaded locally. Do not replace it with a CDN or runtime npm dependency.
- The release app has no user-facing log file (`tauri-plugin-log` is debug-only). Use the Settings → Diagnostics copy action for bug reports.

## Server/protocol
- Protocol changes require matching edits in `server/src/index.js`, `client/src/lib/types.ts`, and `client/scripts/smoke.mjs`.
- `server/src/config.js` loads `server/.env` manually; real environment variables win. Voice uses only Google STUN by default; set `TURN_URL` / `TURN_USERNAME` / `TURN_PASSWORD` for restrictive NATs.
- `server/data/` is persistent production data. Never delete or overwrite it during an update.
- The server is an unauthenticated MVP and uploads are publicly fetchable; do not widen its exposure without discussing it.

## Release and ops
- Bump the patch version on every release in all four files: `client/package.json`, `client/src-tauri/tauri.conf.json`, `client/src-tauri/Cargo.toml`, `server/package.json`. Record the new version and installer SHA-256 in `done.md`.
- Do not deploy or restart production without an explicit request. The server already runs other pm2 apps; never touch them. Slopcall's process is named `slopcall`.
- Do not implement the deferred features listed in `prompt.md` (“do not build yet” and “super extra features”).
- Tray, global hotkeys, and single-instance behavior are Windows/Tauri-specific; verify them in `npm run tauri dev` or the installed app, not just the browser.
